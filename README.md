# ICCC (In-Circuit Continuity Checker)

ICCC（In-Circuit Continuity Checker）は、部品が実装された電子回路基板上で安全に配線の導通確認を行うための携帯型導通チェッカーです。  
マイコンに Microchip ATtiny85 を採用し、Arduino環境で開発・ビルドを行っています。

---

## 概要

一般的なマルチメーター（テスター）の導通チェック機能では、テストリード間に1V〜数V程度の電圧が印加されます。そのため、基板上の半導体素子（ダイオードやトランジスタのPN接合）がオンになり、意図しない経路で導通音が鳴ってしまうことがあります。

ICCCは、テストリード間の印加電圧をダイオードの順方向降下電圧（実測約0.555V）以下に制限することで、シリコン半導体をオンにすることなく、配線本来の導通・短絡のみを安全に確認できます。

---

## 主な特徴・機能

### 1. インサーキット検査対応（低測定電圧）
- **低印加電圧**: テスト端子のバイアス電圧をダイオード（D5: 1N4007）の順方向降下電圧（実測約0.555V）に制限。シリコン半導体素子の閾値（約0.6V〜0.7V）を超えないため、回路上の部品をオンにしません。
- **保護回路**: クランプダイオード（D6〜D8）および電流制限抵抗（10kΩ）により、テスト端子からの入力保護を行っています。

### 2. 抵抗値に応じたブザー発音の出し分け
測定した微小抵抗値（ADC値）に応じて、音色・鳴り分けを行います。
- **完全導通（約10Ω未満 / ADC値 < 2.0）**: 高音連続音（2776Hz）
- **低抵抗導通（約10Ω〜50Ω / ADC値 2.0〜10.0）**: 中音断続音（920Hz）
- **絶縁状態（約50Ω以上 / ADC値 >= 10.0）**: 無音  
※分圧抵抗（2.2kΩ）により、ADC分解能は約5Ωとなっています。

### 3. 電源状態の表示と電池残量警告
- **電源ON表示LED**:
  電源が投入されると白色LED（D3）が点灯し、通電中であることが一目で分かります。
- **電源ON時の電池残量チェック**:
  起動時にバッテリー電圧を計測します。
  - 電源電圧が十分にある場合：ブザー短音（「ピッ」と短音）が鳴り、測定待機状態に入ります。
  - 電源電圧が低い場合（残量不足 / 1.7V未満）：**ブザー長音**が鳴った後に自動的にシャットダウンします。
- **動作中の電池残量監視**:
  動作中に電池電圧が低下した場合（0.9V未満）：**ブザー長音**が鳴った後に自動的にシャットダウンします。

### 4. 電源管理
- **プッシュスイッチ操作**: 短押しで電源投入（マイコンによる自己保持）。長押しで手動電源オフ。
- **オートパワーオフ**: 最後のテスター検知から60秒間無操作が続くと、自動で電源がオフになります。

### 5. 音量調整
基板上の半固定抵抗（VR1: 0〜500Ω）により、電磁ブザーの発音音量を手動で調整できます。

## ハードウェア仕様

### 基本仕様
- **マイコン**: Microchip ATtiny85 (DIP-8)
- **動作クロック**: 内部 1MHz
- **開発環境**: Arduino環境
- **電源**: 単3乾電池 × 2本 ＋ DC-DC昇圧コンバータ（5V出力）

### ピンアサイン (ATtiny85)

| ピン番号 | ポート | 信号名 | 入出力 | 接続先・機能説明 |
| :---: | :---: | :---: | :---: | :--- |
| 1 | PB5 | `/RESET` | 入力 | プルアップ抵抗（47kΩ）経由で+5Vに接続 |
| 2 | PB3 (A3) | `Vin_Batt` | アナログ入力 | バッテリー電圧監視入力（分圧・電流制限抵抗経由） |
| 3 | PB4 (A2) | `ADC` | アナログ入力 | テストリード導通判定入力 |
| 4 | GND | `GND` | - | グランド |
| 5 | PB0 | `BUZ_out` | デジタル出力 | ブザー駆動出力（N-ch MOSFET 2N7000経由、電磁ブザー） |
| 6 | PB1 | `SIG_SW` | デジタル入力 | 電源/操作プッシュスイッチ入力 |
| 7 | PB2 | `EN_PWR` | デジタル出力 | 電源自己保持制御出力（Highで保持、Lowで遮断） |
| 8 | VCC | `VCC` | - | 電源（昇圧5V） |

## ビルドおよび書き込み手順

本ファームウェアは Arduino 環境で開発・ビルドされています。

### 1. 準備
- Arduino IDE を用意します。
- ボードマネージャより **ATTinyCore**（または対応するATtiny用コア）をインストールします。

### 2. ボード設定
Arduino IDEの「ツール」メニューで以下のように設定します。
- **ボード**: ATtiny25/45/85 (No bootloader)
- **チップ**: ATtiny85
- **Clock Source**: 1 MHz (internal)

### 3. 書き込み
1. 書き込み装置（Arduino as ISP、USBasp、AVRISP mkII等）をPCおよびATtiny85に接続します。
2. 初回書き込み時またはクロック設定変更時は、「ツール」→「ブートローダを書き込む」を実行してヒューズビットを設定します。
3. `iccc.ino` を開き、「スケッチ」→「書込装置を使って書き込む」を実行して書き込みます。
